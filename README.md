## Monster Team

**Monster Team - Zombie Escape** is a Counter-Strike 1.6 Zombie Escape community developed and maintained by me.

The project includes custom AMX Mod X plugins, gameplay systems, server infrastructure, web services, Discord integrations, and community tools.

## Development

- Custom AMX Mod X / Pawn plugins
- Counter-Strike 1.6 gameplay systems
- Zombie Escape systems
- Discord bots and automation
- Websites and dashboards
- Backend APIs and database systems
- Game server monitoring and management
- Server infrastructure and deployment
